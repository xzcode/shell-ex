# Shell EX 产品需求与验收基线

版本：0.1.0 / 2026-11-23。产品方向：A，完整桌面 SSH 客户端。面向个人日常开发与 Linux 服务器管理，首发 macOS Apple Silicon。

## 产品原则

终端占据主要工作区；主机、文件、监控辅助操作。主机配置与布局留在本机，敏感凭据进入系统凭据库。浏览器预览如实标注自身能力，不模拟成功连接。所有按钮对应实际命令或明确禁用状态。

M0–M5 描述实现顺序，不表示经过五轮点击就完成验收。以可运行代码、实际测试和安装包构建记录为准。

## 关键业务流程

连接：选择主机 → 探测身份 → 用户核验/已有信任匹配 → 获得临时或系统凭据 → SSH 认证 → PTY → 独立辅助通道。

远程编辑：读取内容+元数据版本 → 修改 → 保存前核验 → 写同目录随机临时文件 → 同步/关闭 → 保留权限 → 再次核验 → 原子替换。SFTP 不提供跨进程 compare-and-swap；外部写入者在最终核验与 rename 之间仍可能竞争。文档不承诺消除所有跨进程竞争。

目录传输：只读展开（不跟随符号链接）→ 规模/冲突预览 → 选择策略 → 验证计划未过期且源未变 → 创建必要目录 → 每文件进入同一传输引擎 → 逐项真实结果。不会把部分成功汇总成全部成功。

重连：连接终止 → 显示旧终端记录 → 手动或有界退避重试 → 新握手/身份/认证 → 新 shell。身份变化、缺少凭据和交互式挑战转为人工处理。

## 本版明确约束

文件编辑 UTF-8 <=5 MiB，结构化命令输出 <=2 MiB/30 秒，目录规划最多 1000 文件/2048 条目/32 层，计划 5 分钟过期，每个文件验证后才能续传/发布。这些边界在 UI 或具体错误中可见。

云账号、云同步、网络线路加速、插件市场、MCP 适配、自动 sudo 文件部署、任意 SSH 配置指令解释和旧算法兼容开关不属于 0.1.0。M5 的正式对外分发需要额外的发行身份证书，不可由开发代码代替。

## 质量门槛

类型/编译检查必须通过。身份验证、文件完整性、权限与指纹边界、取消和清理用行为测试验证。真实 OpenSSH 与受控认证协议服务器分别覆盖互操作和边界；不能把受控 echo fixture 当作真实服务器终端程序兼容性报告。签名安装包、实际 macOS 系统凭据库和 Windows 实机体验需要对应平台证据。

# Shell EX v0.3.0 — 应用内加密凭据与连接编辑简化

本版包含 v0.2 的终端/监控/底部 SFTP 工作台改版，并实现独立于 macOS Keychain 的 SSH 密码管理方案。

## 主要功能
- 将 SSH「身份认证」页合并到「基本信息」；连接配置现在只有「基本信息」「网络」「高级」三个页签。
- 新建连接的默认密码保存位置为 **Shell EX 本地加密库**，另外允许系统凭据库和“仅本次使用”。
- 本地密码库位于操作系统分配的 Shell EX 应用数据目录下的 `credentials.sqlite3`。只保存通过 Argon2id（64 MiB/3 次）派生主密钥、AES-256-GCM 加密的 SSH 密码与私钥口令。每条记录使用不同随机 nonce，主机 UUID 作为认证附加数据。主密码不落盘、不存入系统 Keychain。
- 首次保存时设置主密码，支持解锁、锁定和修改主密码；退出应用清除内存中的密钥。解锁后自动读取该模式已保存的密码。
- 安全升级：已有 v0.1/v0.2 主机缺省仍使用原系统凭据库。切换时先保存新目标密文、再处理旧副本，失败时尽量回滚并呈现错误。旧 Keychain 无法删除时允许用户手动清理。
- “仅本次使用”只保存连接参数，连接时输入密码，不会把密码持久化。
- 加密备份可选择包含受支持的已解锁凭据，导入时按备份主机对应的存储位置写回。

## 安全注意事项
本地密码库使用独立主密码；**遗忘主密码后，无法解密本地已保存的服务器凭据**。请保管主密码及应用数据目录备份；重装、迁移时推荐加密导出备份。

主机地址、主机名及设置仍以普通 SQLite 保存，只有 SSH 密码/私钥口令存入本地加密库。磁盘加密及本机登录安全仍由操作系统负责。程序不会存储 SSH 主机密码明文或在浏览器预览中保存它们。

旧连接使用的 Keychain 不会被未经确认的升级强制迁移。若从 Keychain 切换至本地加密库时系统拒绝删除旧凭据，新凭据可能已经保存但旧副本仍存在，用户应在系统凭据管理器检查。

## 安装及已知限制
本 Release 含 macOS Apple Silicon DMG、Windows x64 NSIS EXE、Linux x64 DEB，以及 SHA-256 校验和构建来源记录。私有仓库下载需要访问权限。

macOS 个人构建使用 ad-hoc 签名，未经过 Developer ID 公证；Windows 未签名；应用内签名更新默认关闭。跨系统密码迁移请使用“数据与备份”中的加密备份。完整功能及边界参见 README 和 docs/RELEASE.md。

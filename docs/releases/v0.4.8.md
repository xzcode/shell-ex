# Shell EX v0.4.8 — Native context menus and reliable column resizing

- Prevents the default WebView context menu (including Reload) across the main and detached monitor windows, without stopping application context-menu handlers or keyboard editing.
- Completed downloads have Open downloaded file and Show in folder actions in the transfer queue and its right-click menu, plus Copy local path. Names and local paths reflect the actual saved file.
- The native action accepts only a completed download task ID; missing or redirected files and unfinished tasks are rejected. macOS reveals the file in Finder, Windows selects it in Explorer, and Linux opens its containing folder using the system file manager.
- Enlarges file-table resize targets, uses a positioned block inside each header and window-level mouse move/up listeners instead of table-cell pointer capture. Widths remain persisted; double-click resets the column.
- Fixes the native Rust handler type-inference error that blocked the v0.4.7 installers. Includes its resizable directory tree, monitoring width and independent monitor window.

Browser and core tests exercise these behaviors without launching local applications or connecting to a production host. Native Finder/Explorer behavior and real macOS WebView interaction require a desktop installation check.

# Shell EX v0.4.6 — Integrated macOS title bar

- macOS uses Tauri's overlay title bar, hiding the native title text and separate gray strip while preserving the original close, minimize and full-screen controls.
- The app toolbar reserves 100 logical pixels for the native controls; its empty spacer supports window dragging and the framework's title-bar double-click behavior.
- Search, settings and other interactive controls remain clickable. Windows, Linux and browser preview keep their original title bar layout.
- Includes v0.4.5 offline Linux command reference and idle workspace logo.

Native window-control placement, dragging and full-screen behavior require a macOS launch check; browser tests cover layout and interaction boundaries only.

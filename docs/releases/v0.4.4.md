# Shell EX v0.4.4 — Stable settings window

- Settings uses a consistent viewport-bounded window size across all six sections.
- Navigation and header/footer stay fixed; only the right-hand settings content scrolls when needed. Each section opens at the top, and small desktop windows retain visible Cancel and Save controls.
- Other dialogs retain their original content-sized layout. Includes all v0.4.3 changes.

Native installation packages are built and verified by the release workflow.

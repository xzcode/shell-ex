# Shell EX v0.4.0 — Interface languages / 多语言界面

- English and Simplified Chinese interface; system language by default.
- Change language under Settings → Appearance → Interface language.
- Language preference persists locally; no application restart or SSH reconnect is required.
- Localized connection management, file panels, terminal controls, monitoring, tunnels, Docker, settings, and known application-generated messages.
- User-provided names, commands, paths, host settings and credentials are preserved. Remote output and third-party controls may retain their original language.

简体中文：新增跟随系统、简体中文和 English 三种界面语言选项。在设置 → 外观 → 界面语言中切换并保存。已有连接、密码库与 SSH 会话保持不变。

## Distribution

macOS Apple Silicon (DMG, ad-hoc signed, not notarized), Windows x64 (NSIS, unsigned), Linux x64 (DEB). Each installer is distributed with SHA-256 and exact source commit metadata. The formal release is published after all three platform packages have been uploaded and verified.

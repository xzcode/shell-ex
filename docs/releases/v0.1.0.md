# Shell EX v0.1.0

Shell EX 首个正式桌面发行版本，完成 M0–M5，面向个人服务器管理、终端操作、文件传输和日常运维。主机配置与工作区保存在本机，凭据使用系统凭据库，不依赖云账号。

构建来源：`7c5b2e547dabb48de4d42cfd00ed4dde5181cf87`。

## 主要功能

- **连接与终端**：真实 SSH、本地 PTY、多标签及上下/左右分屏；支持密码、私钥、SSH Agent 和交互式认证，连接前核验服务器指纹。
- **文件与编辑**：SFTP 浏览、目录上传下载、传输队列、暂停与校验续传；目录复制先预览再执行，同名文件可跳过或覆盖。远程文本保存检查版本冲突，避免静默覆盖外部修改。
- **网络与工作区**：代理、跳板机、本地/远程/动态转发、保守的 SSH config 导入、工作区恢复、快捷命令和深浅主题。
- **运维与数据**：Linux 资源及进程监控，Docker 容器、镜像、日志与启动/停止/重启，加密备份及恢复。
- **终端可靠性**：输出确认有界重试，持续通信失败清理所属会话；手动关闭取消自动重连链，晚到的新连接会被关闭，关闭失败保留可操作错误。

## 已知边界

macOS 使用 ad-hoc 签名，尚未经过 Apple Developer 公证；Windows 未做 Authenticode 签名，系统可能提示未知发布者。自动更新默认关闭，当前通过下载安装包更新。

传输恢复仅限当前应用进程，暂不支持重启后恢复队列；编辑器仅支持 UTF-8，单文件上限 **5 MiB**。远程原子覆盖依赖服务器扩展，不支持时返回明确错误。普通 SSH 重连创建新 shell，不恢复断线前的进程。

Linux 包在 Ubuntu 24.04 x64 构建，需要图形会话及兼容的系统库；本次 Mac 仅提供 Apple Silicon 包。三平台构建成功不代替每台设备的系统凭据库、权限与安装体验验收。升级或退出前请保存编辑内容并处理正在运行的传输。

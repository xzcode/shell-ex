# Shell EX v0.4.1 — Local credentials / 本地凭据

- Includes the v0.4.0 English/Simplified Chinese interface and simplified empty workbench.
- Removes the system credential-store option and the native keyring dependency.
- Old system-backed or missing-mode host records are read as builtin local storage; host IDs, configuration and trust data are unchanged.
- Passwords stored only in the old OS vault need to be re-entered. The default checked option saves the new credential only after successful authentication, without reading or deleting old Keychain entries.
- Legacy in-app vaults and session-only storage remain supported; existing builtin encryption data is unchanged.

中文：不再主动访问系统钥匙串。旧连接无需重建；第一次连接可重新输入服务器密码并本地加密保存。保留旧的本地加密库和已有配置。界面默认跟随系统，可选择简体中文和 English。空闲工作台保持空白。

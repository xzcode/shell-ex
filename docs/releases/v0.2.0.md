# Shell EX v0.2.0 — 工作台体验更新

基于 v0.1.0 的 SSH/SFTP 核心，改进桌面布局、文件管理与 Linux 监控；不改变既有主机、凭据和隧道的存储语义。

## 功能变更
- **全宽底部文件面板**：终端与监控并排在上，文件/传输/快捷命令/Docker 面板在下，支持拖动调整高度；隐藏辅助面板后终端使用剩余空间。
- **SFTP 文件管理**：新增懒加载目录树，显示文件名、类型、大小、修改时间、POSIX 权限与服务器提供的 UID/GID；保留安全上传下载、目录规划、冲突处理和远程编辑。
- **丰富的监控面板**：Linux CPU、内存、Swap、运行时间、负载、内核、CPU 核数、网卡流量、进程与磁盘挂载点，另有 CPU/网络趋势曲线。采样值来自真实只读 SSH 命令，无数据时显示“—”。“采样耗时”是 SSH 命令执行及返回耗时，不是 ICMP Ping。
- **主题**：石墨灰（新默认）、雾光浅色、极光深色，兼容旧版 dark/light 值。终端配色与界面同步。
- **交互**：代理和跳板 select 与表单输入框统一尺寸；顶部占位搜索栏移除，改为图标和 ⌘K 快捷查找。

## 兼容和边界
现有 `dark` 主题使用更柔和的石墨灰；旧配置、SQLite 主机及系统凭据库保持不变。监控只读采集不会自动操作进程，发送 TERM 仍需确认。

编辑器仍限制 UTF-8 5 MiB，暂停/续传仅限当前应用进程；原子覆盖仍依赖服务器的 SFTP 扩展。macOS 包使用 ad-hoc 签名、未经 Developer ID 公证；Windows 未使用 Authenticode；自动更新默认关闭。三平台打包成功不代表所有真实用户设备均已验收。

## 安装
附件提供 macOS Apple Silicon `.dmg`、Windows x64 `.exe`、Linux x64 `.deb`，以及 SHA-256 校验与构建来源记录。此仓库仍为私有仓库，下载需要访问权限。

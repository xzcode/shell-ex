# Shell EX v0.4.11 — Layered themes and softer light palette

- Adds Neutral Gray and Soft White themes. Neutral Gray uses medium-dark neutral gray surfaces instead of blue-gray backgrounds; Soft White uses muted warm off-white and gray navigation without pure-white workspace surfaces.
- Refines all seven theme palettes. The title bar, connection sidebar, session tabs, terminal, file toolbar, directory tree, file list, table headers, monitoring area, monitoring cards and status bar use explicit semantic surface colors.
- Settings theme previews show the same palette tokens as the live workspace. The settings window remains fixed-size and scrolls internally.
- Terminal ANSI colors, Monaco editor backgrounds and detached monitor themes follow the selected theme. New and older theme IDs are validated by the same native allowlist; existing settings remain compatible.
- Theme selection persists. Automated checks cover region backgrounds, common text contrast, preview consistency, editor/terminal palette matching and legacy configuration compatibility.

Includes v0.4.10 monitor docking lifecycle changes, chart axes, adjustable monitoring columns and compact quick commands. The actual native macOS appearance and repeated docking behavior still require a desktop installation check.

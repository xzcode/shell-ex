# Shell EX v0.4.9 — Resizable transfer queue

- The transfer queue now has five independently resizable columns: file/direction, progress, speed, status and actions.
- Drag a header separator, use its arrow-key controls, or double-click it to restore the default width. The workspace persists column widths, and older workspace data receives compatible defaults.
- Fixed-width data columns preserve adjacent widths; spare space is assigned to a trailing filler, and the queue scrolls horizontally when needed.
- Includes v0.4.8 native context-menu suppression, completed-download Finder/Explorer actions, file-table resizing, resizable directory tree and detachable monitoring.

The native desktop release still requires CI packaging and verification.

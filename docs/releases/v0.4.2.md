# Shell EX v0.4.2 — File manager and pure black theme

- Adds a file-manager context menu: refresh, open, built-in code/plain-text editor, persistent default editor preference, copy path, download, upload files/folders, download archive, create file/directory, rename, delete and permissions.
- Downloads never replace existing local files. Choose another destination if there is a conflict; directory downloads always skip existing files. Atomic no-replace publication protects against a same-name file created during transfer. Upload overwrite remains explicit.
- Archive download uses GNU tar on the connected Linux host with a private staging directory in /tmp. Successful/canceled tasks clean up their archive; cleanup errors report its location. Packing is bounded to five minutes. Failure or disconnection may leave an archive requiring manual cleanup.
- Recursive deletion uses SFTP rather than shell rm, refuses protected roots/home and symbolic-link traversal, scans up to 10,000 entries/32 levels, and requires confirmation. Changes or interruptions may cause a partial result.
- Pure black theme (#000000 terminal and workbench, neutral gray controls) also applies to the built-in editor. Existing themes remain selectable.
- Includes the multilingual UI and removal of Shell EX's system credential-vault dependency from v0.4.1.

The editor choices are internal; external editor launch and automatic writeback are not implemented. Binary files can be downloaded and opened locally. Native packages remain subject to CI packaging and verification.

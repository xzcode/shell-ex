# Shell EX v0.4.7 — Resizable workspace and detached monitoring

- Drag the directory-tree boundary, all six file-table column headers and the docked monitoring boundary. Double-click a resize handle to restore its default width. Arrow keys also adjust focused handles.
- Width preferences are persisted in the existing workspace record. Older records receive defaults; terminal and file-list minimum usable space is preserved.
- Detach the monitor into a separate native window. It follows the active SSH session and uses the existing SSH manager rather than opening another connection. Closing it or choosing Dock returns monitoring to the main workspace. Closing the main workspace closes the detached window.
- Detached monitoring is read-only: its native command allowlist permits only its context, current-session telemetry and docking. Process termination remains in the docked panel.
- The detached window follows the main application's theme, language and sampling interval. Its native frame can be resized and moved to another display.

The focused browser IPC-fixture tests and workspace compatibility test pass. Native multi-window behavior remains subject to platform build and installation verification.

# Shell EX v0.4.17 — Workbench V2 and privileged file operations

## Workspace

- Full-height left monitor, adjustable width, independent dock/detach controls, right-side terminal and tools.
- Resizable table-based connection manager overlay with search, group/favorite filters, sortable/resizable columns, column visibility, batch management and local preferences. No live connection status column.
- Double-clicking a saved connection opens a new independent SSH session. Repeated connections have distinct tabs and isolated files, monitoring and reconnect state.

## Privileged SFTP

- Explicit per-session sudo toggle with permission-denied retry entry; no automatic escalation, no sudoers modifications and no password storage.
- Uses existing passwordless sudo authorization for a fixed OpenSSH sftp-server path. Supports browsing, editing, file operations and file/directory upload/download with existing integrity checks and atomic replacement.
- Privileged transfer records are labeled. Mode exit seals the capability, invalidates plans, cancels unfinished transfers and attempts staging cleanup before revocation. Ordinary SSH sessions remain unchanged.
- Password-required sudo and elevated server-side archive generation remain future work. Abrupt network loss can prevent remote staging cleanup.

## Verification

The workbench and privileged transfer branches passed the core, loopback OpenSSH integration and browser UI workflows before this release. Native desktop packaging and release validation run separately. See [Workbench V2](../design/WORKBENCH_V2.md) for the design and compatibility details.

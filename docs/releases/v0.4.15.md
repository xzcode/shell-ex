# Shell EX v0.4.15 — Windows-to-Linux monitoring fix

- Fix the cross-platform monitor collector line-ending issue: Windows checkouts may embed CRLF in the remote SSH shell script, causing Bash `export` and pipeline syntax errors and preventing telemetry from loading.
- Enforce LF for shell scripts in Git checkouts and normalize embedded CRLF to LF before transmitting the monitor command. The runtime normalization also protects builds from archives or customized checkouts.
- Add a platform-independent regression test that simulates CRLF on the complete collector, plus a Unix shell syntax check for the normalized command. Existing loopback OpenSSH monitoring tests exercise the live collection path.
- No remote package, privileged command, server-side change or configuration migration is required. All v0.4.14 storage, disk I/O and process monitoring behavior is preserved.

Windows native device validation remains separate from the shell and SSH regression tests.

# Shell EX v0.4.16 — Full-width SFTP file list

- Fill the available file-list pane with the existing columns, keeping the checkbox column fixed. Header backgrounds, file-row stripes, hover and selection now extend to the right edge on wide windows.
- Observe the actual list viewport, including non-overlay scrollbars, and redistribute spare width when the window or directory tree is resized. Narrow panes retain column preferences and horizontal scrolling.
- Keep sort targets and resize grips independent. A manual resize preserves the requested column width, shares newly freed space among other columns, and persists the resulting preferences. Automatic viewport changes alone do not overwrite preferences.
- Add column layout tests and wide/narrow viewport regression assertions. All v0.4.15 monitoring fixes are retained.

Browser/CI verification is separate from native desktop visual validation.

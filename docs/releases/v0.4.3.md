# Shell EX v0.4.3 — Desktop interaction polish

- Prevent accidental text selection in host rows, navigation tabs, file-list rows and context menus, including WebKit.
- Right-clicking a saved host now opens its existing connection action menu instead of the browser context menu.
- Terminal, editor and form text selection remain available.
- Includes v0.4.2 file-manager context menu, non-overwriting downloads and pure black theme, plus v0.4.1 local credentials and multilingual interface.

Native installers remain subject to CI build and verification.

# Shell EX v0.4.5 — Offline Linux command help

- Adds a Linux command reference accessible from the left sidebar, quick-connect menu and the usage guide.
- Includes 85 entries in 11 categories, in Simplified Chinese and English: file operations, logs/text, system/disk, processes, networking, services/scheduling, permissions, archives, package management, Docker and SSH/session tools.
- Every entry contains a description, common options, an example and example explanation. Risky operations include explicit cautions.
- Search matches command names, both languages, common parameters, categories and examples. Results and navigation scroll within a fixed-size, theme-aware dialog.
- Examples can be copied, never executed or sent to a terminal automatically. No network connection or SSH session is needed. Installed commands and supported flags depend on the Linux distribution and version.
- Includes earlier improvements to local credentials, file transfer safety, pure black theme and stable settings layout.
- The empty terminal workspace displays only a centered, muted Shell EX application icon. The logo disappears when connecting or opening a session; no welcome copy or extra buttons return.

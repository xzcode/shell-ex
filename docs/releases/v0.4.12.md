# Shell EX v0.4.12 — File sorting and host group management

- All six file-table columns can be sorted ascending or descending. Name sorting uses natural numeric ordering and keeps directories first; size and modification time use raw metadata. Unavailable sizes/times remain last. Column resizing is independent of sorting.
- The sort preference persists locally, works with file filters, and does not reset selected paths when changing sort direction.
- Add named host groups directly from the connection sidebar. Empty groups persist across restarts. Right-click or use a group's actions to create a connection in that group, rename it, or remove it.
- Move saved connections between groups without editing credentials. Removing a group moves its hosts to the default group without deleting their connection configurations, passwords or active sessions. The default group itself cannot be removed.
- Existing groups remain compatible, and the original free-text group field and its suggestions continue to work. Empty-group metadata is stored in the local configuration database; the older portable backup format does not include empty groups separately.

Includes all v0.4.11 theme changes. Native installation packages remain subject to CI packaging and verification.

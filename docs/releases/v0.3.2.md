# Shell EX v0.3.2 — 内置通用离线加密，免主密码

## 改动

现在新建 SSH 连接的“密码保存位置”默认是 **本地加密保存（默认）**。只输入服务器密码一次，保存连接，之后直接使用。

- 固定内置 AES-256-GCM 密钥，不再生成随机的 `auto-vault.key` 文件，也无需用户设置或解锁任何主密码。
- 使用每条凭据独立的随机 nonce 和主机 UUID 作为 AAD，把密文保存在 `builtin-vault.sqlite3`。
- 无云服务依赖、无需 Keychain、无需单独的密钥文件；完全离线。
- 保留 `system`（老版系统凭据库）、`local`（旧主密码库）、`auto`（v0.3.1 随机密钥文件库）兼容读取；对新安装不创建 `auto-vault.key`。旧数据不自动删除或强制重加密。
- 仍可选择“不保存密码”，但不是默认值。

## 安全取舍

该设计按个人离线自用的便利性优先。内置通用密钥可以从应用程序提取，因此**拿到程序与密码密文数据库的人可能解密密码**。这不是为防御本机文件窃取而设计的密码保险库。主机和密码数据库仍由本机用户目录权限隔离，建议自行保护系统登录与磁盘。

# Shell EX v0.4.13 — Terminal context menu

- Adds a terminal-specific right-click menu with Copy, Paste, Paste selection, Find, Clear buffer and Set background image. Commands follow the current theme and interface language.
- Copy and Paste selection use the selection captured when the menu opens. Paste uses the local clipboard. Multiline paste retains the configured confirmation, and Ctrl+C remains the terminal interrupt on non-macOS systems.
- Find opens the existing terminal search. Clear buffer clears local terminal output while retaining the current prompt line; no command is sent to the server.
- Select a local PNG, JPEG or WebP image (up to 12 MB), re-encoded to a bounded JPEG, as a subtle shared terminal background. It persists locally and can be restored to the default. It is never sent to the server.
- Includes file sorting and independent host groups from v0.4.12. Empty-group metadata and wallpaper are local preferences, not part of the older portable backup format.

Browser tests exercise the xterm UI with an isolated IPC fixture. Native clipboard and file picker behavior on macOS still require a desktop check.

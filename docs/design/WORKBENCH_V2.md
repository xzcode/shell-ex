# Workbench V2

- Move the docked monitor to the left, full workspace height. The right workbench contains terminal tabs and the bottom tools. The monitor width, hide and native detach/dock actions remain available.
- The connection manager opens as a resizable overlay (1060 × 620 logical pixels initially). Group filters, search, a sortable/resizable table, optional columns, selection, batch move/delete, favorites and existing editor/import/export actions are available. No connection status or online marker is displayed in this manager.
- A double click always creates another independent SSH session. Tabs distinguish repeated opens; their terminal, monitor, SFTP and close operations use the session ID. Workspace restoration preserves repeated host IDs up to the existing 100-entry validation limit. Automatic reconnection follows the affected source session, not all tabs of the same host.
- The connection database and normal SFTP privilege model are unchanged. Last successful connection time, manager size and column preferences are local UI data; older backups do not include these new preferences.

## Privileged SFTP (v0.4.17)

An explicit file-browser sudo toggle uses a separate capability and existing non-interactive sudo authorization. A fixed allowlist of OpenSSH sftp-server locations is probed; the elevated binary channel receives no terminal PTY, password, arbitrary shell command or sudoers change. Browsing, editor saves (including atomic replacement), and file operations use the elevated capability only. Exiting the mode, switching tabs, unmounting the file panel or disconnecting revokes it. Ordinary terminal, monitor, tunnels and SFTP retain the login identity. File and directory upload/download use the same isolated SFTP capability, including integrity checks and atomic overwrite. The queue labels elevated tasks. Revocation first seals the capability against new transfers, drops outstanding plans, then cancels unfinished tasks and attempts staging cleanup before closing the channel. Switching to the transfer panel preserves the active file capability; switching SSH tabs, hiding the tools or closing the session revokes it. Abrupt network loss may prevent remote staging cleanup. Server-side archive generation remains ordinary-only. Password-required sudo is a later stage. The isolated OpenSSH fixture tests root-only access, owner mismatch, separate tabs, ordinary permissions, atomic editing and revocation.
